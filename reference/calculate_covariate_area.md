# Calculate the area for each value of a covariate

**\[experimental\]**

## Usage

``` r
calculate_covariate_area(
  covariate_raster = NULL,
  covariate = c("kgc", "pb", "phz")
)
```

## Arguments

- covariate_raster:

  a terra raster object of covariate data

- covariate:

  a string representing the covariate, either 'kgc', 'pb', or phz'
