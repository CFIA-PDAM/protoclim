# Calculate a weed species' climate suitability across covariate levels

**\[experimental\]**

## Usage

``` r
calculate_climate_suitability(gbif_occurrence_data = NULL)
```

## Arguments

- gbif_occurrence_data:

  a data frame of occurrence data extracted from GBIF. Augmented with
  covariate data via
  [`add_covariates()`](https://cfia-pdam.github.io/protoclim/reference/add_covariates.md)
